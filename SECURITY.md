# Security policy

## Supported service

Security fixes are applied to the current production release at https://anywaypossible.com.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository instead of opening a public issue:

https://github.com/anyway-possible/public-api/security/advisories/new

Include the affected endpoint, reproduction steps, potential impact, and any suggested mitigation. Do not include secrets, private keys, or personal data. We will acknowledge a complete report as soon as practical and coordinate remediation before public disclosure.
